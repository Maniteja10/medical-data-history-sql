# Medical Data History Analysis Using SQL

## Project Overview
This project analyzes medical data using MySQL to extract insights about patients, hospital admissions, diagnoses, allergies, and doctors.

## Tools Used
- MySQL
- MySQL Workbench
- SQL
- GitHub

## Database Tables
- Patients
- Admissions
- Doctors
- Province Names

## SQL Concepts
- SELECT, WHERE, ORDER BY
- GROUP BY and HAVING
- Aggregate functions
- Joins
- String functions
- Date functions
- CASE statements
- Data cleaning and updates

## Key Analysis
- Patient demographics
- Hospital admissions
- Diagnosis analysis
- Allergy distribution
- Patient weight groups
- BMI calculation
- Doctor specialty analysis

## Project Files
- `Medical Data History.sql` — SQL queries for medical data analysis.

## How to Run
1. Install MySQL Workbench.
2. Connect to an authorized MySQL database containing the required tables.
3. Open the SQL file.
4. Select the appropriate database.
5. Execute the queries and review the results.

## Skills Demonstrated
SQL querying, data aggregation, filtering, joins, data validation, and analytical problem-solving.

## Security
No database passwords, private connection details, or confidential patient information should be published in this repository.
